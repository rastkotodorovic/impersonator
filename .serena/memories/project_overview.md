Laravel 13 app named Impersonator. Purpose: a WhatsApp auto-reply experiment that uses a user’s exported Facebook/WhatsApp message history to retrieve stylistic/contextual examples and generate replies in the user’s voice. Main flows: connect WhatsApp via WAHA, import Facebook export data, generate embeddings into Meilisearch, test prompts in a chat UI, and enable auto-replies for selected contacts. Core services: WahaService, OpenAIService, MeilisearchService, MessageRetrievalService, AutoReplyService. Controllers expose WhatsApp session management, OpenAI auth/API-key storage, chat testing, profile management, and auto-reply contact toggles. Views include dashboard, WhatsApp management, auto-reply UI, and chat interface.
